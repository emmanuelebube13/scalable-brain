## One root cause fixed, not just the symptom

`oanda_ingest.log` reappeared at the root minutes after being moved, because
`src/layer0/ingest_data/ingest_oanda_prices.py` defaulted its `LOG_FILE` to the bare
relative name `"oanda_ingest.log"` — so every run started from the repo root dropped one
there. The default is now `logs/oanda_ingest.log`, and the `--log-file` argument's default
and help text read from that single constant instead of repeating the literal.
`pytest src/layer0 -q` → 454 passed.
