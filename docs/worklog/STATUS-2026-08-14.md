### What the summary scalars were hiding

## 5. Engine change made today

`position_engine.py` rejected **every** `ExitLeg(kind="trailing")` while its message said
*"fractional… use StopRule.trail_atr_multiple (whole-position trailing)"* — advice the code
refused to honour. Three of four affected strategies used `fraction = 1.0`, exactly the case
the message calls supported. Root cause was a contract gap: `OrderIntent` demands ≥1 exit leg
summing to 1.0, so a "trail until stopped out" strategy had no legal way to express itself.

Fix: reject only `fraction < 1.0`; derive the trail from `StopRule.trail_atr_multiple` when
set, else from a whole-position trailing leg's `atr_multiple` **or `pips`** (fixed-pip
trailing is new); StopRule wins when both are declared, so one mechanism described twice
trails once. The old guard test asserted the blanket rejection using `fraction=1.0` —
mislabelled — and was replaced by three tests.

Result: `demark_fractal_breakout` 0 → 2,714 trades, `kpl_donchian_breakout` 0 → 359,
`janus_swing_system` 0 → 6. Three strategies moved from *never measured* to *measured and
failed*. They were invisible before, not disproven.
