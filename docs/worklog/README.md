# docs/worklog/ — session and agent completion records

Dated records of what happened during a session or what an agent completed.
The distinction from `task/` is that these are *records of work done*, not work to do.

## What is in this folder

The June 2026 `DONE_*_agent_*.md` files are completion records from the initial agent
build-out (2026-06-24). Each records what a specific agent accomplished.

## What goes here

- End-of-session records: what happened, what changed, what was left open
- Agent completion summaries when they do not belong beside a specific task
- Dated notes that are records rather than plans

## Naming

`YYYY-MM-DD.md` for session records, or `DONE_<agent>_<timestamp>.md` for agent completion.

## Choosing between worklog and task

- Something with a definition of done → `task/`
- A record of something already done → here
- A day-to-day running log → here

## Do NOT put here

- Open work items (→ `task/`)
- Design documentation (→ `docs/design/`)
- Issues noticed in passing (→ `issues/`)
