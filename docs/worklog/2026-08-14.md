## 2. FIX-S1-014 — the contaminated champion, pulled

`Range_Stochastic_Divergence` (strategy_id 10) was **the entire live model** — 4 map cells, all of
it. Its divergence detection uses a centred rolling window, so it reads five bars into the future
and **emits zero signals when computed causally** (audit, 2026-08-02).

**The non-obvious part:** regenerating the map would not have removed it. The attribution rows
still show PF 1.92 / Sharpe 1.07, because they derive from outcomes produced by the look-ahead
version. A fresh `vet --live` would have re-qualified it, and hand-editing the map file would be
undone by the next run. So the bar had to be **in code, ahead of the gates**.

It is deliberately not in `gates.py`. Gates encode *performance* thresholds — failing them is a
near miss that could be fixed by improving. Strategy 10 cannot improve; its metrics are fiction.
Recorded as a separate `integrity_fail` category carrying its own reason string.

Result: **8 integrity rejections** (4 regimes × 2 granularities). Map empty. Registry zeroed.

**Side effect handled:** two existing `test_gates.py` tests used `strategy_id=10` as an arbitrary
fixture id and began failing. Rather than renumber them — fragile, the next barred id breaks them
again — `build()` gained an injectable `disqualified` parameter, and those tests now pass
`disqualified={}` to state that they test *weighting*, not integrity policy.
