# docs/goals/ — targets and milestones

Strategic goals, value ladder milestones, and metrics frameworks for Scalable Brain.

## What is in this folder

| File | What it covers |
|---|---|
| `VISION.md` | **Start here.** The mandate (strategic capital growth), what the name means, the evidence-gates-vs-risk-caps distinction, the risk ladder, the compounding arithmetic, and the four phases. Sits above everything; revised yearly, not weekly |
| `IDENTITY_AND_HABITS.md` | Who has to exist for the vision to happen — goals → why → beliefs → identity → habits → skills, for the owner *and* for agents. Includes the named agent failure mode: caution optimised for blame-avoidance builds a system that never trades |
| `VALUE_MILESTONES.md` | The value ladder as written: M0 = where we are; M1 = honest zero; M2 = first honest qualifier; M3 = 6-month forward test; M4 = verified 12-month curve. *(This row previously said "M1 → M10" and called M3 "first live order" — neither matches the file; corrected 2026-09-13.)* |
| `SYSTEM1_METRICS_AND_TARGETS.md` | Quantitative targets for System 1: pipeline freshness, signal quality, gatekeeper performance |
| `SEPTEMBER_2026_GOALS.md` | Period goals for September 2026 — get the live map onto honest post-fix evidence before the 09-15 hold expiry |
| `JULY_2026_GOALS.md` | Period goals for July 2026 |
| `2026-08-AUGUST-WEEKEND-GET-TRADING-STARTED.md` | The August 2026 weekend goal: get one real order placed |

## What goes here

- The vision, the mandate and its phases
- Beliefs, identity and habits — for the owner and for agents
- Period goals (monthly, quarterly)
- Value-ladder milestone definitions and their done conditions
- Metrics and targets frameworks

## Do NOT put here

- Work items with a task definition (→ `task/OPEN.md` or `task/backlog/`)
- Research results or analysis (→ `docs/research/`)
- Design decisions (→ `docs/design/`)
