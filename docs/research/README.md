# docs/research/ — research notes and exploratory analysis

Papers, ML research notes, exploratory analysis, strategy screening outputs.
The one `docs/` subfolder that is allowed to accumulate heterogeneous material.

## What is in this folder

| File | What it covers |
|---|---|
| `websitereviewonhmm.md` | Third-party article on HMM market regime overlays (reference material) |
| `TOP-10-CANDIDATES-2026-08-23.md` | Top-10 strategy candidates screened on 2026-08-23 |
| `RESEARCH_NOTES_QUICKSTART.md` | Quickstart guide for the research notes API |
| `ml/` | ML research notes |
| `*.pdf`, `*.csv` | Papers and data files used for strategy research |

## What goes here

- External research papers and articles (PDF or markdown summary)
- Notes from exploratory analysis sessions
- Strategy screening and candidate shortlists
- ML research notes that inform system design

## Do NOT put here

- Work items (→ `task/`)
- Formal design decisions (→ `docs/design/`)
- Explanatory docs about how the system works (→ `docs/design/`)
