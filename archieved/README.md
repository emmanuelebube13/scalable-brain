# archieved/

Frozen history only: a `.zip` and its `.sha256` manifest, nothing else. If it is
unpacked, it is not archived, it is just moved — see `STRUCTURE.md`.

**This folder is git-ignored (`.gitignore`, section 12) and must not be committed.**
Its contents can be large, are not source, and are not meant to live in repo
history. This `README.md` is the sole exception (see the `.gitignore` allowlist)
so the rule stays visible even though the folder itself is empty from git's
point of view.
